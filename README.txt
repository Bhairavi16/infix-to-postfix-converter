Infix to Postfix Converter
Compiler Construction Mini Project

HOW TO RUN
1. Unzip this folder.
2. Double-click index.html (opens in Chrome, Edge, Firefox or Safari).
No installation or server needed.

FEATURES
- Lexical analysis: token table (type, lexeme, column)
- Syntax analysis: shunting-yard algorithm with step-by-step trace
- Postfix output with copy button
- Syntax tree, three-address code, postfix evaluation
- Error messages with exact column

OPERATORS (precedence, associativity)
^ (4, right)   unary - + (3, right)   * / % (2, left)   + - (1, left)
