Grammar and operator rules

OperatorMeaningPrecedenceAssociativity
^Exponent4 (highest)Right
u- u+Unary minus and plus3Right
* / %Multiply, divide, remainder2Left
+ -Add, subtract1Left

expr → term { (+|-) term }   term → factor { (*|/|%) factor }   factor → unary [ ^ factor ]   unary → (+|-) unary | primary   primary → NUMBER | IDENT | ( expr )

Operands may be numbers (including decimals) or identifiers such as x or total_1. Unary minus is written u- in the postfix output so it stays distinct from subtraction.
